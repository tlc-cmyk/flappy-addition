# 加數小鳥

面向 iPhone 嘅直向加數飛行小遊戲：輕觸螢幕令小鳥向上飛，飛過寫住**正確答案**嘅管子空隙。

> 原創角色同管子美術；唔係 Flappy Bird／其他商業遊戲嘅資產複製。

## 點玩

1. 用 Safari（或 Chrome）打開遊戲頁面，建議直向、全螢幕。
2. 撳「開始遊戲」。
3. **輕觸螢幕任意位置**令小鳥拍翼向上；鬆手就會受重力落下。
4. 頂部顯示算式（例如 `4 + 5 = ?`），可選顯示蘋果／積木計數提示。
5. 前方管子有 2～3 個空隙，每個空隙有一個數字——**只可以飛過正確答案**嗰個。
6. 飛對：+1 分；自動難度下每 10 分升 1 級（共 10 級）。
7. 撞管、飛錯空隙、撞地：扣 1 命，短暫顯示正確答案後重試同一輪設定；3 命用完結束。

## 設定

右上角 ⚙️ 可調：

| 項目 | 說明 |
|------|------|
| 難度模式 | 自動升級，或鎖定等級 1–10 |
| 管子間距 | 愈大＝思考時間愈長 |
| 重力／跳躍力度 | 操控手感 |
| 管子速度 | 關卡節奏 |
| 空隙大小 | 通過難度 |
| 顯示計數物件 | 算式下方蘋果／積木 |
| 還原預設 | 一鍵恢復預設數值 |

🔊 可靜音。音效為簡易 Web Audio 短音（拍翼／得分／撞到），唔會播兒歌旋律。

## 數學設計

只做**加法**。等級大致由「10 以內」過渡到「過十」：

- 少用純「湊十」題（例如 3+7）
- 加入**雙同數**（4+4、6+6…）
- 中高階偏重兩邊較大、和超過 10 嘅算式（例如 5+7、8+6）

## 本機開

純靜態頁，無需 build：

```bash
cd flappy-addition
python3 -m http.server 8080
# 瀏覽器打開 http://localhost:8080
```

或直接用 GitHub Pages 連結（見下方）。

## 技術

- `index.html` + `styles.css` + `game.js`（Canvas）
- iPhone Safari：`viewport-fit=cover`、大範圍輕觸拍翼、直向
- 設定存於 `localStorage`
